# 魔方实验室

韭菜盒子中的独立静态小游戏，无第三方运行时依赖。通过网站首页进入，或从仓库根目录启动静态服务器后访问 `/games/rubik/index.html`。需要通过 HTTP 访问，以加载 ES modules 和求解 Worker。

- 在色块上按住滑动转动魔方；从空白处开始拖动改变观察角度。支持鼠标与触屏，也可使用 U/R/F/D/L/B 键，Shift 加字母为逆时针。
- 提供 3、6、20 步随机打乱、撤销、计时、自动还原与暂停/继续。打乱会开启新一局。
- 使用 54 个面片的整数坐标置换，动画与状态采用同一旋转约定。
- Worker 中进行双向广度优先搜索，最多搜索六次 90° 转动，范围内返回最短解。范围外使用本局可逆操作记录还原，不声称是通用最短解。
- 色块环形图显示 48 个活动面片，省略 6 个不动的中心。节点颜色与魔方一致，轨道直接由真实转动置换生成，每个面转动由五个四循环组成。球面投影经过径向压缩，让远端轨道和节点在同一画面内可读；静态显示相邻面的循环轨道，转动时补充并高亮被转动面自身的循环。两侧动画共用同一进度，十二种转动的终点都与面片置换一致。
- 游戏不保存到服务器，刷新会重开。尊重系统的减少动态效果设置。

验证：`node --test games/rubik/model.test.mjs`。

灵感来自用户提供的 TheMathFlow「用图论解魔方」分享和环形图截图，采用独立绘制的色块轨道图，未复制原作代码。
